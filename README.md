# Login Form

A clean, responsive login form built with HTML, CSS and a bit of JavaScript for basic interaction and validation.

![Login Form Screenshot](./Screenshot%202024-07-02%20182203.png)

## Demo
Open `index.html` in your browser or serve the folder with a static server (for example, using the VS Code Live Server extension).

## Features
- Simple, modern UI built with HTML & CSS
- Basic client-side validation with JavaScript
- Fully static — no backend required
- Lightweight and easy to customize

## Files
- `index.html` — Markup for the login form
- `style.css` — Styling and responsive rules
- `Screenshot 2024-07-02 182203.png` — Example screenshot included in the repo

## How to use
1. Clone the repository:

   git clone https://github.com/BinaryVortex/Login-Form-35.git

2. Open the project folder and double-click `index.html` or run a local static server.

3. (Optional) Customize `style.css` and `index.html` to change colors, spacing, or add fields.

## Customization tips
- Change the color variables in `style.css` to match your brand.
- Add more client-side validation in `index.html` (or an external JS file) for stronger checks.
- Replace the screenshot with your own when you update the UI.
